# Tendracore (web)

Build jogável do Tendracore (Unity WebGL), publicado pelo GitHub Pages:
https://henriquelpmendonca.github.io/tendracore-web/

Este repositório contém só o build. O código-fonte fica no repositório privado do projeto.
Para atualizar: gere `BuildWebGL.BuildGitHubPages` na Unity (sem compressão: o GitHub Pages compacta sozinho), copie o conteúdo de `Builds/GitHubPages` para cá e faça commit + push.
